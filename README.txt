VERSÃO COM FOTOS E MAIS ESPAÇO PARA EVENTOS

Foi adicionada uma seção "Eventos & atividades" com 8 cards quadrados para fotos.

Cada card possui:
- área quadrada para a foto;
- nome do evento;
- descrição curta;
- visual responsivo.

As fotos podem ser substituídas depois pelas fotos reais do projeto.
Desktop: 4 por linha.
Tablet: 2 por linha.
Celular: 2 por linha.
